# تطبيق NutriCare

تطبيق المتجر للعميل. نفس منتجات الموقع، والسلة، وطلب الدفع عند الاستلام. الطلبات تظهر في لوحة الأدمن مع ملاحظة «المصدر: تطبيق الموبايل».

## التشغيل على الموبايل

1. ثبّت تطبيق **Expo Go** من متجر Google Play أو App Store.
2. من مجلد `mobile-app` شغّل:

```bash
npm start
```

3. افتح كاميرا الموبايل وامسح رمز QR اللي يظهر في الطرفية. الموبايل والكمبيوتر لازم يكونوا على نفس الواي فاي.
4. أول مرة التطبيق عربي ومن اليمين لليسار. زر **EN** في الأعلى يبدّل للإنجليزي ويعيد فتح التطبيق.

للتجربة في المتصفح:

```bash
npm run web
```

## مفاتيح الاتصال

الملف `mobile-app/.env` فيه مفاتيح Supabase العامة (نفس مفاتيح الموقع). الملف مش بيتضاف لـ Git. لو نقلت المشروع لجهاز تاني، انسخ القيم دي من `.env` بتاع الموقع:

- `EXPO_PUBLIC_SUPABASE_URL`
- `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
- `EXPO_PUBLIC_ADMIN_EMAIL`

مثال الأسماء موجود في `.env.example`.

## بناء نسخة للتثبيت

النسخة اللي بتتفتح من Expo Go مناسبة للتجربة. عشان تنشر التطبيق على Google Play أو App Store، استخدم EAS من داخل `mobile-app`:

```bash
npx eas-cli@latest build
```

محتاج حساب Expo. الأيقونة الحالية هي أيقونة القالب، وتقدر تستبدل `assets/icon.png`.
